# @internal/plugin-boards-common

Shared types and helpers for the boards plugin: board, column, priority,
item, checklist, comment, change, and permission types; `text:` ref helpers
and permission level utilities; due-date helpers; item filter matching;
comment mention parsing; and the entity-reference label constants. Used by
`@internal/plugin-boards` (frontend), `@internal/plugin-boards-backend`, and
future sync modules.
