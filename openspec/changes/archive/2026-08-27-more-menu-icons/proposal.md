# More Menu Icons

## Why

The board more menu is text-only; leading icons make the entries scannable and consistent with the Remix icon set.

## What Changes

- More-menu entries get `iconStart` icons: `RiHistoryLine` (Recent changes…), `RiArchiveLine` (Archived items…), `RiFileCopyLine` (Duplicate board…), `RiLockUnlockLine` (Share…), `RiDeleteBinLine` (Delete board…, rendered in the danger color).
