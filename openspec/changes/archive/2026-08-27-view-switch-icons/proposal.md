# View Switch Icons

## Why

The board/table view toggle uses text labels; icons make the compact toolbar clearer and match the Remix icon set now used across the plugin.

## What Changes

- The view toggle buttons show `RiKanbanView` (board) and `RiGridLine` (table) icons with accessible labels/tooltips instead of text labels.
